Gruppen einteilen

Gruppenzahl einstellen, dann entweder Automatisch zuteilen klicken oder Farbe wählen und Plätze anklicken beziehungsweise überziehen. Rechtsklick markiert einen Platz als frei. Mit Anordnen lassen sich die Tische verschieben. Tasten: 1 bis 9 wählen die Farbe, 0 ist der Radierer, X der Frei-Stift.

Spielbrett

Alle Teams würfeln, dann kommt die Frage. Nach der Auflösung wird für jedes Team ein Haken (richtig: das Team zieht die Zahl vor) oder ein Kreuz (falsch: das Team geht die Zahl zurück) eingetragen. Auf ❓-Feldern entscheidet ein Glücksrad. Wer oft Pech hat, wird wütend und bekommt irgendwann einen Boost.

📱 Antwort-Gerät

Ein zweites Gerät (Tablet oder Handy) sammelt pro Frage die Antworten aller Teams. Danach werden die Ergebnisse auf das Spielbrett übertragen.

Einrichtung (einmalig)
  1. In der Firebase-Konsole unter „Realtime Database“ eine Datenbank anlegen, Standort in der EU.
  2. Unter „Regeln“ diesen Block ergänzen (ersetzt nicht Ihre anderen Regeln, sondern kommt in „rules“ dazu): 
    "spielbrett": { "$raum": { ".read": true, ".write": true } }
  3. Die Adresse der Datenbank oben eintragen. Die Seite selbst muss im Netz liegen, zum Beispiel über GitHub Pages.

Gespeichert werden nur der Raumcode, die Teamfarben und die Buchstaben A bis D. Keine Namen.
